Camera Streaming

Real-time video via rosbridge (Base64) or MJPEG. Low resolution (640x480) works great with Base64.

LiDAR Visualization

2D scan display using standard sensor_msgs/LaserScan. Compatible with RPLidar, YDLidar, etc.

Multiple Controls

Touch joystick, D-pad buttons, and keyboard (WASD). All output standard geometry_msgs/Twist.

Mobile Ready

PWA support - add to home screen for app-like experience. Works on iOS Safari and Android Chrome.

# Install
cd ~/ros2_ws/src
git clone https://github.com/hwkim3330/ros-websocket.git
sudo apt install ros-humble-rosbridge-server
cd ~/ros2_ws && colcon build --packages-select ros_web_controller

# Run
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/setup.bash
ros2 launch ros_web_controller web_control.launch.py

# Access: http://ROBOT_IP:8080
