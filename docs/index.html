Camera Streaming

Real-time video via rosbridge (Base64) or MJPEG. Low resolution works great with Base64 encoding.

LiDAR Visualization

2D scan display using sensor_msgs/LaserScan. ~10fps refresh rate for smooth visualization.

Multiple Controls

Touch joystick, D-pad buttons, and keyboard (WASD) support. Works on mobile and desktop.

Mobile Ready

PWA support - add to home screen for app-like experience. Responsive design for all screens.

# Install
cd ~/ros2_ws/src
git clone https://github.com/hwkim3330/ros-websocket.git
sudo apt install ros-humble-rosbridge-server
cd ~/ros2_ws && colcon build --packages-select ros_web_controller

# Run
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/setup.bash
ros2 launch ros_web_controller web_control.launch.py

# Access: http://ROBOT_IP:8080
